# Geometric Consistency of Planar LiDAR–Anchored Monocular Depth for Indoor 3D Reconstruction

## Overview

This repository contains the experimental dataset associated with the research article entitled “Geometric Consistency of Planar LiDAR–Anchored Monocular Depth for Indoor 3D Reconstruction.”

The dataset was acquired during an indoor experimental session on 26 September 2026 using an RPLIDAR A1 planar laser scanner and a conventional RGB webcam. The study investigates the geometric consistency of sparse LiDAR-anchored monocular depth conversion for indoor 3D reconstruction.

## Dataset Contents

- Original RGB camera images
- Raw LiDAR measurements
- Estimated LiDAR trajectories
- Camera-LiDAR pose association logs
- Per-frame 3D point-cloud records
- Reconstructed XYZRGB point clouds
- Three-dimensional voxel representations
- Two-dimensional occupancy maps
- Gazebo-compatible mesh and environment exports

## Data Access

The complete experimental dataset is provided as SupplementaryMaterial_S1.zip under Release v1.0.0.
